**Java Virtual Machine (JVM)** 
- What it is: An engine that loads and executes Java bytecode.
- Main job: Converts bytecode into machine-specific instructions for your computer.
- Key feature: Provides platform independence ("write once, run anywhere").

**Java Runtime Environment (JRE)** 
- What it is: A bundle of software used to run Java programs.
- What it contains: The JVM plus core class libraries and supporting files.
- Who it is for: End-users who only want to run Java applications, not write code.

**Java Development Kit (JDK)** 
- What it is: A full-featured kit used to build Java applications.
- What it contains: The JRE plus development tools like a compiler (javac) and debugger (jdb).
- Who it is for: Programmers and developers who write and compile code.
