FAQ

Common questions

Do you use Bootstrap or Tailwind?

For learning and client work I prefer custom CSS so you understand every line. Frameworks are great later — fundamentals first.

What's your typical turnaround?

A one-page portfolio like this takes about 5–7 days including revisions. Rush delivery is possible for fest deadlines.

Can you help with college projects?

Yes — I mentor on HTML/CSS structure, responsive layouts, and viva-ready documentation. I don't write entire assignments for you.

Are you open to remote internships?

Absolutely. I'm based in Mumbai but collaborate with teams across India on GitHub and Figma.
